### The Pitch

Echo Engine is a specialized engine for understanding the systems and patterns used in commercial video game engines. It offers a simple and easy-to-understand abstraction, ideal for students and professionals looking to enhance their skills in computer graphics.

Echo Engine is designed to facilitate continuous learning in the architecture of graphics engines, utilizing techniques, patterns, and systems common in commercial video game engines like Unity or Unreal Engine.

Echo Engine focuses on providing the necessary tools for any developer to understand the fundamental classes required to manipulate engines at this level.

Echo Engine includes:

- Entity Component System (ECS)
- Mathematical library for vectors and matrices
- Custom classes for smart pointers
- Specialized structures for dynamic memory storage
- Graphical interface provided by IMGUI
- Classes designed for loading FBX models
- Complete abstraction of the DirectX11 API for resource manipulation
- Use of third-party libraries for texture loading
